Add RADIUS devices

One device: one IP and one name. Several: separate them with commas, names in the same order as the IPs. Leave Name empty to use the IPs as names.

All devices added together use the same shared secret, vendor and device type. IPs that are already in NAS Clients are skipped and left unchanged. Single IPs work immediately; a network (CIDR) entry restarts FreeRADIUS once (about a second).
