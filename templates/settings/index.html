Backup automationDefine when backups run and how missed schedules are recovered.
AUTOMATION

Scheduled backup

Choose how often the system should back up every configured device. Choose specific days of the month, such as the 1st and 15th, or any dates from 1 to 31. A configuration file is saved only when the configuration changes.

↻

Choose one or more dates. Backups run at the selected time. Dates unavailable in a month (for example, the 31st in February) are skipped.

Choose the calendar dates and run time for recurring monthly backups.

Missed-run recoveryIf the server is temporarily offline at the scheduled time, run the missed backup when service returns, for up to 24 hours. Device-level retries remain separate.

02
Backup performanceSet safe concurrency for device connections and backup processing.

Performance

How many devices are backed up at the same time. For 500 devices, the system checks ICMP first, then uses a limited number of SSH sessions. Total time depends on device response and configuration size. Only one backup job runs at a time.

03
Data retentionChoose how long operational backup logs remain available.
DATA MANAGEMENT

Log retention

Control the retention period for historical device backup log entries. Saved configuration files are not affected.

▤

Older Logs-page entries are deleted automatically once a day. Saved configuration files are not deleted.
